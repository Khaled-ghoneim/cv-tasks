# Task 2: Face and Eye Detection

This folder contains two webcam face and eye detection examples:

- `task2.py` uses OpenCV Haar Cascade classifiers.
- `yolo_face_eye.py` uses the YOLO face and pose models stored in this folder.

See the project [README](../README.md) for environment setup, dependency installation, and commands to run either program from the project root. Press **q** in the preview window to quit.
